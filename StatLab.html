Why this is Topic 1

Every AI model starts from the same place: numbers that need to be described before they can be learned from. Here's where each idea actually shows up later on.

→ → →

Data → described (μ, M, mode, σ, σ²) → fed into models → powers ML / DL / Gen AI

Baselines & lossA classifier's simplest baseline predicts the mode; a regressor's predicts the mean. MSE — the most common loss function in ML — is literally the mean of squared errors.

NormalizationEvery ML pipeline scales features with (x−μ)/σ before training. BatchNorm and LayerNorm compute this exact pair of numbers live, inside the network, on every forward pass.

Deep learning internalsThe formulas used to randomly set a neural network's starting weights are literally variance calculations — get it wrong and signal explodes or fades away across layers. The bias-variance tradeoff, which explains why models overfit or underfit, is named directly after this same statistic.

Generative AIDiffusion models add noise on a variance schedule, then learn to reverse it. Transformer attention scales by √d to control the spread of scores. Sampling temperature reshapes that same spread.

Data quality & outliersComparing mean vs. median instantly reveals skew — the same quick check used to catch mislabeled rows or corrupted features before they poison a model.

That's why stats comes before everything else in AI.
